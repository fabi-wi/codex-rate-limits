# Codex Rate Limits 0.2.2

Codex Rate Limits 0.2.2 keeps working when OpenAI returns only one active usage window and is ready for additional window durations in future responses.

## Highlights

- Displays a weekly limit even when the 5-hour window is absent.
- Discovers every non-null usage window returned in the main Codex rate-limit response.
- Labels hourly, daily, weekly, and monthly durations automatically.
- Adapts the menu-bar rings, tooltip, popover rows, and popover height to the windows that are actually available.
- Continues to support the original local JSON format for development and demos.

## Install

Download `CodexRateLimits-v0.2.2-macos-arm64.zip`, unzip it, and open `CodexRateLimits.app`.

The app is not notarized in this release. If macOS blocks first launch, right-click the app and choose **Open**.

## Requirements

- macOS 14 or newer
- Apple Silicon Mac for the prebuilt app bundle
- Current ChatGPT desktop app with Codex, or the legacy standalone Codex app
- Codex signed in with your ChatGPT account
- `~/.codex/auth.json` present on the machine

## Privacy

The app reads `~/.codex/auth.json` locally and uses the access token in memory to request usage data from `https://chatgpt.com/backend-api/wham/usage`. Tokens are not logged or stored by this app.
