# Codex Rate Limits 0.2.0

Codex Rate Limits is a lightweight macOS menu-bar companion for keeping Codex 5-hour and weekly usage visible while working.

## Highlights

- Live Codex rate-limit updates from the same usage source used by the Codex desktop app.
- Native macOS menu-bar app with no Dock icon.
- Two concentric circular indicators: outer weekly limit, inner 5-hour limit.
- Translucent macOS material popover with a clean Whoop-inspired layout.
- Automatic companion launch when Codex.app opens, and automatic close when Codex quits.
- Top-right close button that keeps the companion closed for the current Codex session.
- Local JSON mode remains available for testing and demos.

## Install

Homebrew:

```bash
brew install --cask fabi-wi/tap/codex-rate-limits
```

Manual download:

Download `CodexRateLimits-v0.2.0-macos-arm64.zip`, unzip it, and open `CodexRateLimits.app`.

The app is not notarized in this release. If macOS blocks first launch, right-click the app and choose **Open**.

## Requirements

- macOS 14 or newer
- Codex desktop app signed in with ChatGPT
- `~/.codex/auth.json` present on the machine

## Automatic Launch With Codex

From the source checkout:

```bash
./scripts/install-codex-launcher.sh
```

This installs a local LaunchAgent that opens Codex Rate Limits when `/Applications/Codex.app` is running.

## Privacy

The app reads `~/.codex/auth.json` locally and uses the access token in memory to request usage data from `https://chatgpt.com/backend-api/wham/usage`. Tokens are not logged or stored by this app.
