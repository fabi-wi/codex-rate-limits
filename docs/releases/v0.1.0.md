# Codex Rate Limits 0.1.0

Codex Rate Limits is a lightweight macOS menu-bar companion for keeping Week Limit and 5 Hour Limit usage visible while working in Codex.

## Highlights

- Native macOS menu-bar app with no Dock icon.
- Two concentric circular indicators for rate-limit visibility at a glance.
- Liquid-glass popover treatment inspired by polished health-tracking menu panels.
- Local JSON data source that updates automatically while the app is running.
- Optional LaunchAgent that opens the app automatically when Codex.app is running.

## Install

Download `CodexRateLimits-v0.1.0-macos-arm64.zip`, unzip it, and open `CodexRateLimits.app`.

The app is not notarized in this release. If macOS blocks first launch, right-click the app and choose **Open**.

## Local Data Source

By default, the release app uses its Application Support data file. For development or custom integrations, run with:

```bash
open CodexRateLimits.app --args --data-file /absolute/path/to/ratelimits.json
```

Expected schema:

```json
{
  "weekLimit": { "used": 62000, "limit": 200000 },
  "fiveHourLimit": { "used": 16500, "limit": 50000 },
  "updatedAt": "2026-05-05T14:23:00Z"
}
```
