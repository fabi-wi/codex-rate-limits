# Codex Rate Limits 0.2.4

A cleaner usage display with native macOS popover edges.

## Changes

- Let macOS draw the popover background, rounded corners, border, and shadow; removed the overlapping custom glass layer and manual window positioning.
- Follow the system's light or dark appearance.
- Show a compact countdown such as `resets in 5d 23h 03m 47s`, all in the same font and size.
- Remove the separate days, hours, minutes, and seconds captions.
- Use consistent availability colors in the popover and menu bar: green at 50% or more remaining, yellow from 20% to below 50%, red below 20%.
- Build with the macOS 26 SDK for the current native appearance.

## Install

Download `CodexRateLimits-v0.2.4-macos-arm64.zip`, unzip it, and move `CodexRateLimits.app` to Applications.

Requires Apple Silicon and macOS 14 or newer. The app is ad-hoc signed, not notarized.
