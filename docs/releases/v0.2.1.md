# Codex Rate Limits 0.2.1

Codex Rate Limits 0.2.1 restores automatic menu-bar launch for the current ChatGPT desktop app while retaining support for the legacy standalone Codex app.

## Highlights

- Detects `/Applications/ChatGPT.app` as the current Codex desktop host.
- Continues to support legacy `/Applications/Codex.app` installations.
- Keeps automatic shutdown and close-for-this-session behavior aligned with either host.
- Continues to read live 5-hour and weekly Codex/agentic usage windows from the local ChatGPT sign-in.

## Install

Download `CodexRateLimits-v0.2.1-macos-arm64.zip`, unzip it, and open `CodexRateLimits.app`.

The app is not notarized in this release. If macOS blocks first launch, right-click the app and choose **Open**.

## Requirements

- macOS 14 or newer
- Apple Silicon Mac for the prebuilt app bundle
- Current ChatGPT desktop app with Codex, or the legacy standalone Codex app
- Codex signed in with your ChatGPT account
- `~/.codex/auth.json` present on the machine

## Automatic Launch

From a source checkout:

```bash
./scripts/install-codex-launcher.sh
```

This installs a local LaunchAgent that opens Codex Rate Limits when either `/Applications/ChatGPT.app` or `/Applications/Codex.app` is running.

## Privacy

The app reads `~/.codex/auth.json` locally and uses the access token in memory to request usage data from `https://chatgpt.com/backend-api/wham/usage`. Tokens are not logged or stored by this app.
