# Codex Rate Limits 0.2.3

Maintenance update for installation, refresh reliability, and reset countdowns.

## Changes

- Fixed a first-launch crash caused by looking for bundled sample data in the development checkout.
- Live mode no longer creates a demo data file.
- Concurrent refreshes share one request, time out after 20 seconds, and cancel when the provider stops.
- Failed updates show a warning in the menu bar and the time of the last successful reading.
- Missing usage values no longer appear as full availability.
- Added detailed days, hours, minutes, and seconds countdowns while preserving support for flexible usage windows.
- Added request, decoding, countdown, and relocated-installation regression checks.
- Updated GitHub Actions and made release packaging validate the version, architecture, archive, and signature.

## Install

Download `CodexRateLimits-v0.2.3-macos-arm64.zip`, unzip it, and move `CodexRateLimits.app` to Applications.

Requires Apple Silicon and macOS 14 or newer. The app is ad-hoc signed, not notarized.

## Verification

- Core and request lifecycle tests in GitHub CI
- Release app build and relocated first-launch smoke test
- Archive integrity, signature, and SHA-256 checksum checks
